# Personal Finance Tracker

A simple command-line Personal Finance Tracker built with Python.

## Features

* Add income records
* Add expense records
* View income and expense records
* View records by month
* Generate monthly reports
* Set budgets for expense categories
* Compare budgets with actual expenses
* Edit transactions by ID
* Delete transactions by ID
* Backup financial records
* Persistent data storage using CSV files
* Input validation for amounts and dates
* Unique transaction IDs

## Data Storage

Financial records are stored in CSV files inside the `data` folder.

* `income.csv` stores income records.
* `expense.csv` stores expense records.
* `budgets.csv` stores category budgets.

## Backup

Backup files are stored inside the `backup` folder.

## How to Run

Run the main Python file:

python main.py

Then use the menu to select the desired option.

## Requirements

* Python 3.14.7
* No external libraries are required.
